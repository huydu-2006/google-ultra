Cancel before the trial ends. Play → profile → Payments & subscriptions → Subscriptions → Google One → Cancel. You keep the remaining trial time.

"Not signed in": the link goes through Google's account chooser first. If you entered an email, it locks onto that account; if not, pick the account in the prompt. Still failing? Check that the browser is not blocking Google cookies, or open the link in the browser where that account is signed in.

Seeing 400: Google rejected the request before rendering checkout. Common causes: (1) the account/IP is not US, or no payment method is attached; (2) the hardcoded offer token in the web version has expired (use the script version to query a live token); (3) the browser fingerprint does not match (open the link in the same browser that generated it; do not copy it to another browser; try Compatibility mode).

"You're not eligible for a free trial": the account has no trial left. You need a payment method attached and no active subscription. One trial per account — don't test on your main one.
